## Scope
Standalone scientific/financial quantitative preview, not advice or source validation. One immutable owner-transcribed dataset, separately pinned original source bytes, source reference and ISO as-of date. BAR (signed, zero baseline) or LINE (numeric X positions in increasing order, no category spacing masquerading as time); three to five points. Integer fixed-point values +/-999999 and 0–3 decimal places; precise displayed values, same axis and geometry in both languages, no hidden float rounding. Positive/negative domains include zero; mixed-sign range symmetric. Zero-only data and excessively close X positions rejected. Shared explicit units, exact value table, color-keyed points, visible source date and unverified-data warning. No forecasts, uncertainty bands, currency conversions, log axes or implicit data imputation. Original source file is hash-bound only: transcription, interpretation, translation, license, and factual accuracy require human review.

Data JSON fields: schema VIRALOS_CHART_DATA_V1, source_sha256, source_reference, as_of (YYYY-MM-DD), kind BAR or LINE, unit (ASCII 1–16 chars), decimals (0–3), x_unit and x_decimals (null for BAR, same constraints for LINE), rows (ordered {id:1-based, value:integer, x:null or integer}). Dataset and source pins separately retained. Request JSON: schema VIRALOS_BILINGUAL_CHART_REQUEST_V1, data_sha256, format SHORT/LONG, languages {hindi,english}; each language has font_sha256, font_rights_attested:true, license_reference, title, labels (same count/order as dataset). Hindi uses pinned Devanagari font and mandatory RAQM/cmap/GSUB; English uses pinned font cmap and BASIC layout. ASCII numeric labels/warnings use Pillow's default font. Explicit bounded glyph boxes; no silent shrink or clipping. Use short labels.
