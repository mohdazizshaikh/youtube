Request schema VIRALOS_BILINGUAL_DYNAMICS_REQUEST_V1, scenes ordered {scene,frames}, tracks {hindi,english} each complete Phase 15X dynamics request (including independent voice SHA-256). Two to eight scenes, 13–750 frames per scene, total 75–3000 frames; 640 samples per 25 fps frame. Both tracks must match exact shared sample count, clean source QC, distinct input PCM and same declared LUFS target and dBTP ceiling. Independent compression/limiting parameters permitted. Each track processed through Phase 15X; actual output true peak checked. Split mastered PCM only at exact declared frame boundaries, verify sample reassembly, report each scene's QC flags and reject silent scenes. No padding, trim, crossfade or shifting. Both target proximity and cross-language loudness difference <=2 LU are diagnostics, not automatic pass gates. Listening required. No professional or owner acceptance.
